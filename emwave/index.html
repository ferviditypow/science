電荷的運動

紅線是電場線。直接拖曳紅色電荷可以自己移動它：甩一下、突然停住，電場線上的「彎折」會以光速往外跑——那就是電磁波。右邊藍色的接收天線就像收音機的天線，彎折傳到時，天線裡的電子（藍點）會被推得上下動，這就是「收到訊號」；接收天線也可以拖曳。動畫中的光速已大幅放慢。

    重點

    • 變動的電場產生變動的磁場、變動的磁場又產生變動的電場，擾動不需要物質就能自己往外傳：電磁波。
    • 產生電磁波的關鍵：帶電粒子做加速度運動（振盪、圓周運動、減速）。
    • 口訣：有電、有加速，才有電磁波。
    • 接收天線放在電荷振盪方向的正上方或正下方，幾乎收不到訊號——電磁波主要往和振盪方向垂直的方向發射。

    電磁波的六大性質

    • 橫波：電場、磁場與前進方向三者互相垂直（所以電磁波能「偏振」）。
    • 不需要介質：畫面中沒有任何物質在動，只有場在變化；太陽光就是穿過真空來到地球。
    • 真空中速率都是 c ≈ 3×10⁸ m/s，和頻率、波長、能量無關。
    • c = fλ：頻率越高，波長越短（到「電磁波譜」實驗台拖曳看看）。
    • 進入介質後速率變慢、頻率不變、波長變短。
    • 能傳遞能量，也有反射、折射、繞射、干涉等所有波的行為。
    中間放

    左邊的感應線圈讓兩根金屬棒之間跳出火花，電荷在棒子裡快速來回振盪，發出電磁波（紅、藍表示電場方向相反）。拖曳右邊的接收環換位置，看它的小缺口會不會也跳出火花。

    赫茲的實驗（1886–1888）

    • 馬克士威 1879 年過世時，還沒有人「抓到」過電磁波。
    • 赫茲用感應線圈在一對金屬球間製造高頻火花；幾公尺外，有小缺口的金屬環缺口處也跳出微小的火花。
    • 他還證明這種波會反射、折射、偏振，速率等於光速——完全證實馬克士威的預言。頻率單位 Hz 就是紀念他。

    記法

    • 頻率由低到高：無線電波 → 微波 → 紅外線 → 可見光 → 紫外線 → X 射線 → γ 射線（口訣「無微紅可紫 X γ」）。
    • 可見光：紅光頻率最低、紫光最高。
    • 主線：頻率越高、能量越大 → 紫外線會破壞 DNA（曬傷、殺菌）、X 光能穿透肌肉、γ 射線能殺死癌細胞。
    • 各波段之間沒有明確的分界線，不同書本的數值可能略有出入。
