      兩條循環

      體循環左心室 → 主動脈 → 小動脈 → 全身微血管 → 小靜脈 → 上、下大靜脈 → 右心房
      肺循環右心室 → 肺動脈 → 肺部微血管 → 肺靜脈 → 左心房
      • 動脈端的氧氣比靜脈端多，例外：肺（肺動脈 < 肺靜脈）。
      • 動脈端的養分比靜脈端多，例外：小腸（飯後吸收養分，靜脈端較多）。
      • 尿素：肝臟製造（靜脈端較多），腎臟濾出（靜脈端較少）。
      • 從手臂靜脈注射的藥物，一定先經過右心房 → 右心室 → 肺，再回到左心，才能送到全身。
