原子軌域、量子數與電子組態

四個實驗台：軌道與軌域差在哪（電子雲是怎麼來的）、s／p／d 軌域的 3D 形狀與節面、四個量子數怎麼決定一個軌域、電子組態怎麼填。對應講義〈原子軌域、量子數〉與〈軌域能階、電子組態〉。

邊界包住的機率

每一點代表「某一次測量時發現電子的位置」。測越多次，點越密的地方就是電子出現機率越大的地方——這團點就是電子雲；把 90～95% 的點包起來的範圍，就是課本說的軌域。

波耳的「軌道」和量子力學的「軌域」差在哪

  • 軌道（orbit）是空間中一條固定的路徑，電子像行星一樣沿著它跑，位置隨時都算得出來。
  • 軌域（orbital）是空間中的一片區域，我們只知道電子大概在這片區域裡的某處，無法同時準確知道它的位置與動量（海森堡測不準原理）。
  • 1923 德布洛依提出物質波、1926 海森堡提出測不準原理、同年薛丁格用波動方程式解出電子在核外各處出現的機率，量子力學的原子模型就是這樣來的。
  • 電子雲較濃密處＝出現機率較大；雲外仍有可能發現電子，只是機率很低——所以才要用「90～95%」來畫邊界，軌域沒有真正的硬邊。

現在這一團

1s 的最可能半徑剛好是波耳第一軌道的半徑 a₀（0.529 Å）——但意義完全不同：波耳說電子就在那個圓上，量子力學說那裡只是最常被找到的半徑。

形狀是怎麼決定的

  • s 軌域（ℓ＝0）：球形對稱。同一個球面上各點機率相同，和方向無關。每一個主殼層都有 1 個。
  • p 軌域（ℓ＝1）：啞鈴形，沿 x、y、z 三個軸各一個，三者互相垂直、能量與形狀相同，n ≥ 2 才有，共 3 個。
  • d 軌域（ℓ＝2）：n ≥ 3 才有，共 5 個。其中 4 個是四葉草形（dxy、dxz、dyz、dx²－y²），dz² 長得不一樣（上下兩葉加一圈甜甜圈）。
  • 節面＝電子出現機率為 0 的面。角節面有 ℓ 個（平面或錐面）、徑節面有 n－ℓ－1 個（球面），合起來一定是 n－1 個。

（n, ℓ, mℓ）決定一個軌域；再加上 ms，（n, ℓ, mℓ, ms）決定一個電子。同一個原子裡不可能有兩個電子的四個量子數完全相同（包立不相容原理）。

能階順序

單電子系：能階只由 n 決定，ns＝np＝nd＝nf。多電子原子：由 n＋ℓ 決定，n＋ℓ 越大能階越高；n＋ℓ 相同時，n 越小能階越低——這就是 4s（4＋0＝4）排在 3d（3＋2＝5）前面的原因。

填電子的三個原則

  • 遞建（構築）原理：從能量低的軌域先填，再依序往上。能階相同時先填內層（n 小的）。
  • 洪德（罕德）定則：同一副殼層的幾個軌域能量相同，電子要先以相同自旋各佔一個空軌域（先半滿），全部半滿後才允許自旋相反的電子配對進去。
  • 包立不相容原理：一個軌域最多 2 個電子，且自旋必須相反；換句話說，一個原子裡任兩個電子的四個量子數不可能完全相同。
  • 三個都符合＝基態；違反遞建或洪德＝激發態；用到不存在的軌域（2d、3f…）或一格擠 3 個電子＝不可能存在。

這個原子／離子

填的時候先 4s 再 3d，游離的時候卻要先游離 4s 再游離 3d——因為一旦填進去，3d 的能量就比 4s 低了。₂₆Fe：[Ar]4s²3d⁶ → Fe²⁺：[Ar]3d⁶ → Fe³⁺：[Ar]3d⁵。

軌域沒有硬邊

「軌域就是電子跑的範圍」只對一半。軌域是用 90～95% 機率畫出來的統計區域，在邊界外還是有可能找到電子，只是機率很低。所以 s 軌域的圖畫成實心球，不代表電子被關在球裡。

節面不是「電子穿過去」

節面上機率恰好是 0，電子永遠不會出現在那裡。這在古典圖像裡很怪（怎麼從左葉跑到右葉？），但電子不是小球、沒有連續軌跡，問「怎麼穿過去」這個問題本身就預設了軌道的圖像。

ψ 的正負不是電荷

p、d 軌域兩葉常塗不同顏色，那是波函數的相位。機率是 |ψ|²，兩葉的機率都是正的。相位要到講軌域重疊（鍵結軌域／反鍵結軌域、混成）才派上用場。

4s 比 3d 先填，但不代表 4s 比較低

多電子原子的能階用 n＋ℓ 判斷，所以空的時候 4s（4）比 3d（5）低，先填 4s。但電子填進去之後，3d 反而降到 4s 以下，所以游離時先掉 4s。Fe²⁺ 是 [Ar]3d⁶ 而不是 [Ar]3d⁴4s²。

Cr、Cu 的例外

半滿（d⁵）與全滿（d¹⁰）的交換能使系統較穩定，所以 ₂₄Cr 是 [Ar]3d⁵4s¹ 而不是 3d⁴4s²，₂₉Cu 是 [Ar]3d¹⁰4s¹ 而不是 3d⁹4s²。考試常考「哪個原子不成對電子最多」——答案通常是 Cr（6 個）。

量子數的範圍記法

n＝1,2,3…；ℓ＝0 ~ n－1（所以沒有 1p、2d、3f）；mℓ＝－ℓ ~ ＋ℓ（所以 3d 的 mℓ 不可能是 3）；ms 只有 ±½（不可能是 ±1 或 3/2）。考試的「不可能的量子數組合」幾乎都是踩這四條其中一條。
